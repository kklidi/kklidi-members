# Release 0.7.27

## Members 라우트 공통 UX 정리

- 모든 Members 라우트에서 사이트명 브랜드 줄을 제거했다.
- 짧은 화면은 뷰포트 중앙에 배치하고, 내용이 긴 화면은 상단 안전 여백에서 시작하도록 공통 shell을 정리했다.
- 로그인·회원가입·비밀번호 찾기·계정·프로필·동의·탈퇴·로그아웃 화면의 공통 링크를 한 줄 구분자 구조로 통일했다.
- `표시명(닉네임)`과 “로그인 아이디로 사용되지 않음” 안내를 가입·프로필 화면에 추가했다.
- WordPress Core 인증, user ID, 라우트 소유권, 메일 발신자 정책은 변경하지 않았다.

검증: `tests/harness/test_runner.py` 41개 단위 하네스와 배포 카탈로그 검증 통과.
